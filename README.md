# 🌦️ Weather App

A simple and responsive weather application built with React and Vite. Search for any city to check its current temperature, weather conditions, and humidity.

## 🌐 Live Demo

**[Visit Weather App](https://cmwr.vercel.app/)**

## ✨ Features

- 🔍 Search weather by city name
- 🌡️ Temperature displayed in Celsius
- ☁️ Current weather conditions
- 💧 Humidity information
- ⚡ Loading indicator
- 📱 Responsive user interface
- ❌ Error handling for invalid city names

## 🛠️ Tech Stack

- React.js
- JavaScript
- Vite
- Tailwind CSS
- OpenWeatherMap API
- Font Awesome
- Vercel

## 🚀 Getting Started

### Prerequisites

Install Node.js and npm.

### Installation

Clone the repository:

    git clone https://github.com/iamsachinG/Weather.git

Navigate to the project:

    cd Weather

Install dependencies:

    npm install

Start the development server:

    npm run dev

Open the local URL displayed in your terminal.

## 📦 Production Build

Build the application:

    npm run build

Preview the production build:

    npm run preview

## 🌤️ Weather API

This application uses the
[OpenWeatherMap API](https://openweathermap.org/api)
to retrieve weather information.
